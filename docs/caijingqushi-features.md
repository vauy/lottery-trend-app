# 彩经趋势官方功能清单（逆向分析记录）

> 分析来源：
> 1. 官方《趋势软件入门教程》PDF（41 页，随 PC 客户端分发）
> 2. 安卓 APK（97MB，`m.caiyitong.com.cn/.../types/app`）解包：resources.arsc 字符串池 + assets 业务资源
> 3. 网页版 `caijingqushi.com/qushi/`（Vue+ECharts SPA）内联源码 322 条功能词
>
> 整理日期：2026-10-11。用于对齐官方功能、规划我们的 App。

## 一、图表体系

| 功能 | 官方形态 | 我们的现状 |
|---|---|---|
| 频率K线（趋势图） | 红柱=开出、绿柱=遗漏；**柱高与理论概率挂钩**（理论概率越低红柱越高，独胆红柱≈2.69 倍绿柱） | ✅ 已实现（累计实出−理论） |
| 遗漏K线 | 主图/副图通用，BOLL 叠加 | ✅ 已实现（红/绿档位口径） |
| 遗漏图 | 遗漏球（将出球蓝色、拐点球最多 3 颗）+ 遗漏周期线（白色固定直线=理论周期）+ 遗漏均线（蓝5/绿10/粉20） | ✅ 已实现（含 5/10/20 均线） |
| 多周期 K 线 | 1~N 期聚合；柱长由周期内开出次数决定，开出比理论多=红柱 | ✅ 周期K线（OHLC 聚合+影线） |
| 单周期 / 多周期 / 周期出次 | 三种周期口径 | ⚠️ 部分（周期K线/出次图分开有） |
| 和值 / 跨度 / 合分 | 和值K线、跨度K线、合分0-9 等条件 | ❌ 缺 |
| 组三组六豹子 | 3D 特有指标 | ❌ 缺 |
| 二阶遗漏K / 二阶遗漏图 | 主副图通用 | ✅ 已实现 |
| 出次图 / 周期出次 | 分段出次 | ✅ 已实现 |
| 冷热号 | 快乐8 冷热/遗漏区间选号 | ⚠️ 快乐8 分布热力图有 |
| 副图指标 | 最多 2 个：MACD/RSI/KDJ/ADX/BOLL/遗漏K | ✅ 已实现 |
| MA 均线 | 动态计算 MA5/10/20 | ✅ 已实现 |

| 图例控件 | 点击图例控制系列显示 | ❌ 缺 |
| 同屏 | 上边区域同屏（9 张图）+ 下区域同屏 | ✅ 已实现（2列5行/单列满屏） |
| 左边全屏 / 全屏 | 隐藏侧栏全屏看图 | ✅ 已实现 |
| 超级视图 | 多图对比模式 | ❌ 缺 |
| 保存图片 | 图表存图分享 | ❌ 缺 |

## 二、条件与选号（三栏结构的左栏）

| 功能 | 说明 | 我们的现状 |
|---|---|---|
| 星别/位置/条件 | 三联选择：星别（一二三星）→ 位置（百十个）→ 条件指标 | ⚠️ 用页签+DigitGrid 表达 |
| 指标库 | 上百种指标，星别分类，可下载/添加/删除，VIP 锁 | ❌ 缺（固定指标集） |
| 自定义数据 | 粘贴自己的号码组→命名→保存为常驻指标，每天看走势 | ⚠️ 有粘贴导入但不常驻 |
| 指定大底 | 粘贴大底号码 → 查看趋势 | ⚠️ 复制/粘贴导入号码 |
| 毒胆 | 单码趋势，理论周期 2.69 | ✅ |
| 胆拖 | 胆码最多 9 个、拖码最多 79 个，胆拖不能重复 | ✅ |
| **中出个数** | 号码组合"出几个"：0/01/012/1/12/123/2/23/3 +（重）=含对子豹子 | ❌ 缺（高价值） |
| 交并集/交并集合 | 多组条件求交/并出图 | ⚠️ 随机交并 tab |
| 多指标并集 | 和值/毒胆多组号码合并出图 | ❌ 缺 |
| 等分随机/指定随机/黄金分割/随机胆配 | 选号小工具（10 余款） | ⚠️ 部分（分割/等分参考线有） |
| 单复式转换 / 星别转换 | 三星↔二星条件转换、单式↔复式 | ❌ 缺 |
| 号码拆分 | 大底拆分 | ❌ 缺 |
| 复制/导出号码 | 复制号码、导出号码、转复式复制 | ✅ 部分 |

## 三、统计与工具（右栏）

| 功能 | 说明 | 我们的现状 |
|---|---|---|
| **区间统计** | 框选区间 → 中出个数、最大遗漏、最大连开、开出率、理论周期内外统计、出次排行 | ✅ 本轮新增（统计按钮+弹窗） |
| 查看号码 | 右键查看当前条件号码 | ✅ |
| 查看历史中出 | 历史中出记录 | ⚠️ 区间统计覆盖部分 |
| 概率偏差 | 一组号码在一定期数内实际 vs 理论偏差 | ✅（频率K线累计偏差） |
| 遗漏统计/遗漏线 | 遗漏相关统计 | ✅ |
| **遗漏提醒** | 设置条件，达成时推送「您设置的提醒条件已达成」 | ❌ 缺 |
| 指标说明 | 每个指标有说明文案 | ❌ 缺 |

## 四、彩种支持

官方：福彩3D、排列三、排列五、快乐8、双色球（蓝球走势）、七星彩。
我们：排列三、福彩3D、排列五、快乐8（主四类）✅。

## 五、体验版限制（官方）

- 体验版开奖数据运算仅支持 **100 期**
- 部分指标带 VIP 锁
- 安卓 APP（97MB，原生 Kotlin，加固壳）、PC 客户端（exe）、网页版（功能受限）

## 六、对我们的下一步建议（按价值排序）

1. ✅ 区间统计（本轮已做）
2. **中出个数**（0/1/2/全出 + 重）——官方核心概念，教程用 8 页讲它
3. tooltip 十字准星 + dataZoom 手势缩放（图表交互补齐）
4. 指标库化：把固定指标改为可增删的列表 + 说明文案
5. 自定义数据常驻（AsyncStorage 保存号码组为常驻指标）
6. 和值K线 / 跨度K线（3D/P3）
7. 遗漏提醒（本地通知）
