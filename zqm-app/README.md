# 臻奇妙趋势分析 · 手机版

基于 **Expo 54 + React Native 0.81 + expo-router** 从零编写的彩票趋势分析 App，
针对安卓手机（含横屏）布局，数据来自 **17500.cn 全量历史开奖**。
**不含任何卡密 / 授权 / 登录系统**，安装即可用。

## 二、功能模块

| 页签 | 功能 |
|------|------|
| **走势** | 最近开奖一览（期号 / 号码 / 和值 / 跨度 / 形态）+ 号码分布 |
| **K线** | 频率K线 / 周期K线（左·右对齐）/ 遗漏K线（二阶）/ 遗漏图（MA5·10·25）/ 出次图，可叠加技术指标 |
| **搜索** | 指标搜索（交集 / 并集 + 容错）、遗漏节点形态搜索 |
| **组号** | 按位选号 → 笛卡尔积展开 → 和值 / 跨度 / 奇偶 / 大小 / 质合 / 文本大底过滤 |
| **遗漏** | 当前遗漏 / 平均遗漏 / 最大遗漏 / 欲出几率 / 回补几率 / 冷温热 / 遗漏和 |
| **设置** | 数据源说明、缓存管理、免责声明 |

### K 线模式原理

- **频率K线**：红/阳线=开出，绿/阴线=遗漏。理论周期 T（=1/概率），中出一次长度 +(T−1)，遗漏一次 −1，
  曲线因此长期平衡于理论均值附近。
- **周期K线**：把单期 K 线按周期 N 分段聚合：开盘=段首值、收盘=段尾值、最高/最低=段内极值，
  形成带上下影线的蜡烛图。「左对齐」以首期为基准（图形不随新数据变化），
  「右对齐」以投注期为基准（整体重算）——做几期计划就把周期设为 N。
- **遗漏K线（二阶）**：只统计「遗漏期数落在设定范围内再开出」的情况，符合画阳线（长度 = 1/概率 − 1），
  不符合画阴线（−1）。
- **遗漏图**：节点=每次开出前的遗漏期数，配 5/10/25 期移动均线；均线拐点可辅助判断后续遗漏区间。
- **出次图**：按步长分段统计出现次数。

### 技术指标

MA / EMA / EXPMA / BOLL / MACD / KDJ / CCI / DMI(ADX) / SAR / RSI / W&R / MTM / BBI / ATR，
并支持**指标共振**（多条件同时满足时提示，可设容错个数）。

## 三、图表横竖屏自适应（重点）

所有图表统一走 `src/components/charts/EChartView.tsx`，由三层机制保证「同屏 / 竖屏动态适应、走势不变形」：

1. **容器层**：WebView 内图表容器为 `100vw × 100vh`，始终铺满可用区域；
2. **重绘层**：页面监听 `window.resize`、`orientationchange` 与 `ResizeObserver`，
   尺寸变化后防抖 60ms 调用 `chart.resize()` 重新绘制；
3. **布局层**：RN 侧通过 `useResponsive()` 推导内容宽度，竖屏单列、横屏两列并排；
   蜡烛宽度按可见数量动态限制（`barMaxWidth`），窄屏不挤成一团，宽屏不变成粗块。

此外 y 轴使用 `scale: true`，纵坐标贴合数据真实区间而非强制从 0 起，
因此走势在任意宽度下都保持原有形态，不会被压平或拉伸。

数据更新通过 `injectJavaScript` 增量刷新，**不重建 WebView**，横竖屏切换与参数调整都不会闪白。

## 四、目录结构

```
zqm-app/
├── app.config.ts            # Expo 配置（orientation: default 支持横竖屏）

└── src/
    ├── app/

    │   └── (tabs)/          # 6 个页签：走势 / K线 / 搜索 / 组号 / 遗漏 / 设置
    ├── lib/

    │   └── lottery/
    │       ├── types.ts     # 核心类型
    │       ├── games.ts     # 彩种定义
    │       ├── db.ts        # 本地缓存（紧凑文本格式）
    │       ├── datasource.ts# 17500.cn 抓取 + 中彩网备用 + 种子兜底
    │       ├── targets.ts   # 分析标的
    │       ├── analysis.ts  # K线 / 遗漏算法
    │       ├── indicators.ts# 技术指标
    │       ├── filters.ts   # 号码属性 + 过滤
    │       └── shrink.ts    # 组号缩水
    ├── components/
    │   ├── Screen.tsx       # 屏幕容器
    │   ├── GameSwitch.tsx   # 彩种切换
    │   ├── NumberPicker.tsx # 号码选择
    │   ├── ui/Kit.tsx       # 通用组件
    │   └── charts/          # ECharts 图表层
    ├── hooks/               # useLottery / useResponsive
    └── vendor/              # echarts.min.js 内联源码
```

## 五、运行

```bash
npm install
npm start          # 等价于 expo start
```

手机装 **Expo Go**（与本机 Expo SDK 54 对应），扫码或手动输入地址即可热更新。

详细的 Termux 环境搭建见 [TERMUX.md](./TERMUX.md)。
