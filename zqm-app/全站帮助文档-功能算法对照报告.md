## 二、核心算法原理对照（官方原文 vs 代码实现）

### ✅ 完全一致的 9 项 K线/遗漏算法

| 官方定义（帮助原文） | 代码实现 | 状态 |
|---|---|---|
| 频率K线：理论周期10 → 遗漏一次线段长度「−1」，中出线段长度「9」（cycle−1） | `buildFrequencySeries`：`up = cycle − 1`，down = −1 | ✅ |
| 周期K线：分段聚合，开盘=首期、收盘=末期、最高/最低=段内极值，前后周期收盘相接；左对齐（日期首期基准）/右对齐（投注期基准）；退期 | `buildCandles(cum, records, period, align, back)` | ✅ |
| 遗漏K线（二阶）：符合遗漏范围画阳线（长度=1/理论概率−1），不符合画阴线（−1）；当前遗漏不在范围内时**预先画一根阴线** | `buildOmissionKLine` + chart.tsx 预画阴线逻辑 | ✅ |
| 遗漏图：散点折线 + MA5/10/25 + 拐点值 + 均线延长到当前遗漏 | `OmissionChart`（line+scatter+三线）+ `extendToCurrent` + `findTurningPoints` | ✅ |
| 二阶遗漏：仅当遗漏值符合范围时记录「与上一次符合的间隔期数」（例：从右数第6期符合、前次间隔3期 → 记3） | `buildSecondOrderOmission`（gap 间隔期数） | ✅ |
| 出次图：带圆圈的红色细线，圆圈内数值=前N期（分段周期）内出现次数；蓝/绿/紫=5/10/25期均线拐点；退期 | `CountChart`（红线+圆点+数值）+ `buildCountChart(step, back)` | ✅ |
| 遗漏和：组选（不定位胆）/全胆/直选（定位胆）三口径；直选示例「排列五后三 2022137【24450】→ 3+5+13=21」；组选均值11、≥11 下期约90%回落 | `buildOmissionSums`（group/all/straight） | ✅ |
| 开出遗漏：当期开奖号码的上次遗漏（直选/组选口径） | `buildDrawOmission` | ✅ |
| 指标共振：多指标同时满足画信号，交集模式支持容错（允许N个出错） | `resonance(signals, tolerance)` + 搜索页容错 | ✅ |
